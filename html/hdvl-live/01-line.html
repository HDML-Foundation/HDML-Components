01 — Line: two documents, one chart

Two series drawn from two different documents on one pair of scales. Apple comes from this page's own model — the dynamic-document path. Microsoft comes from the tenant's static document /maang.html?hdml-frame=maang_stock_frame, which is a frame over a frame and therefore reads its parent's columns by their bare names. The two legs are granted by different halves of access.yml, so a missing Microsoft line and a missing Apple line mean different things.

The x scale does not subscribe. A Trino DATE reaches the browser as a string column and a string column on hdml-datetime-scale is a V2 kind mismatch, so the domain is authored and the marks carry the ISO strings.
