06 — Bubble: four channels, four scales

The same 114 stock-years as page 05, with two more channels bound. All four resolve to four scales in scope (V1): x and y are continuous, size is a continuous sqrt scale and color is ordinal.

The size scale is type="sqrt" so that area is proportional to value — the only perceptually honest mapping for a disc. Its range is --hdml-size-min/-max in CSS px, because a radius is a length and lengths are CSS.
