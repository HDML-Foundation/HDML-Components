10 — Radar: two subscribed series on one loop

Both series are subscribed — one frame each, over one model, distinguished by an hdml-filter-by. The mock corpus drew one literal series and one bound one; this folder has no literals, so it is two bound ones, which is the same "multi-source stays legal per widget" claim.

The scores are ranks, not magnitudes. Each measure is min-max normalised across the five MAANG stocks to 0–10, so a 10 means "the highest of these five" and a 0 means "the lowest of these five" — never "good", never an absolute. Microsoft is the 0 on growth and it still multiplied. Min-max across five points is a ranking dressed up as a measurement, and the figure cannot say so by itself.

Row order must match the angle domain, because path segments connect rows in row order. Both frames sort by metric ascending and the scale's literal values is that same alphabetical list.
