03 — Bar: orientation is derived, and a real range

A and B are the same frame twice. There is no orientation attribute: the mark works out which way to point from which channel resolves to the band scale. The two figures differ by nothing except which scale carries values="label" and which way round the bar's x and y are written.

C is a genuine two-column range. A scale subscribes to one column, so neither end of the y domain can be derived — it is authored.
