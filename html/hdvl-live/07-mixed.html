07 — Mixed: dual axis done as siblings

Two y scales over one plot area, as siblings and not as parent and child. Nesting them would be a different statement entirely. Because a scale's children must be homogeneous (V13 — scales xor widgets, never both), every widget lives at a chain tip, and the shared x guides sit inside the volume block, placed first so they paint beneath both blocks' marks.

Which block holds the shared x guides is the author's pick: channel="x" resolves to the one shared x scale from either. DOM order is paint order, so the price block comes second and its line paints over the bars.
